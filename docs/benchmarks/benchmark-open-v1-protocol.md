# Frozen release protocol: benchmark-open-v1

Frozen before executing release runs. Settings and seed rules live in `scripts/benchmark-protocol.ts`; each run records the canonical protocol hash and Git source commit. Engine semantics remain `evo-engine-1`. Any preset/algorithm change requires a new suite ID.

- Twenty independent runs, 200 evaluated generations (0–199), 128 genomes, three rotating common training maps per generation, 1,800 ticks per episode, open arena with 48 food. All body, energy, mutation, tournament, immigration, and elitism settings are explicit in the protocol.
- Fresh seed namespace `benchmark-open-v1:run-N` for initialization, training, evolution, and validation. Pilot seeds are not reused.
- Initial and final champions are selected by training totals in generations 0 and 199. Sixteen fixed validation scenarios per run are evaluated every ten generations and at the initial endpoint. Validation never affects reproduction.
- Compare initial/final champions, the first frozen initial network, seeded random actions, and the scripted controller on the identical validation maps. After training, evaluate all five arms on 64 separate held-out maps per run, from the disjoint `held-out-v1` namespace. Do not tune settings or choose examples using held-out outcomes.
- Report every run, failures, per-run validation/held-out means, paired improvements, median/IQR/range, counts improving and exceeding each baseline, and first scheduled validation improvement (generation index, observed every ten generations; null means not observed). Do not treat episode maps as independent evolutionary replicates. No confidence interval is required for this first release.
- Choose the bundled evolved example from the run nearest median final validation performance; break ties by lowest run index. Pair its initial and final controllers on validation map 0, fixed before viewing trajectories. Preserve Node training provenance; generate archive replay results in pinned Chromium. Report cross-runtime differences separately and retain both runtime fingerprints.
- Preserve per-generation full raw trial results/map definitions, commit IDs, final population checkpoint, endpoint genomes, and all validation/held-out results in workflow artifacts (30-day retention). Commit the compact aggregate report and small release examples. Retain downloaded raw artifacts locally for longer-term analysis; they are not a permanent hosted dataset.
- Record Node/V8, hardware, OS/architecture, source commit, workflow run/attempt, elapsed run time, per-generation compute/save timing and memory samples. Parallel hosted jobs measure throughput on their own runner; their elapsed sum is aggregate compute time, not workflow wall time. The local short pilot estimated roughly 2.2 hours of serial Node core work; twenty independent hosted jobs reduce elapsed waiting without reducing the protocol.

Run explicitly using the **Frozen release benchmark** manual GitHub Actions workflow, or locally with `npm run benchmark:release -- --run N --out NEW_DIRECTORY` for each N from 0 to 19. Existing output directories with a manifest are rejected to prevent mixing results. Failed attempts remain visible; retry the same seed/protocol rather than substituting a favorable run. Correctness/Pages CI never starts this sweep automatically.
